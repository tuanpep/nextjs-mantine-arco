# i18n (next-intl)

No `[locale]` URL segment. Locale is **cookie-only** (`DX_LOCALE`, HTTP-only, one year). Default locale is **Vietnamese** (`vi`); **English** (`en`) is the second locale.

## Files

| Concern          | Path                                                         |
| ---------------- | ------------------------------------------------------------ |
| Locales list     | `lib/i18n/config.ts`                                         |
| Request messages | `lib/i18n/request.ts` (next-intl plugin in `next.config.ts`) |
| Set locale       | `lib/i18n/actions.ts` (`setLocale`, `"use server"`)          |
| Copy             | `messages/vi.json`, `messages/en.json`                       |

**Keep keys aligned** between `vi.json` and `en.json`. Add or rename a key in both files in the same change.

## Message namespaces

- Record features: `Bugs`, `Help`, `Features`, `Feedback`, `Guides`, `Discussions`
- Shell / shared chrome: `Workspace`, `Portal`
- Use `useTranslations("Namespace")` in client screens; match the namespace the screen already uses.

Do not add next-intl proxy or middleware for locale prefixes. Do not add a `[locale]` route segment.

## E2E

Playwright seeds `DX_LOCALE` and exercises the language control. See [testing](testing.md).
